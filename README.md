# Clear Rank one-page landing page prototype

A static HTML/CSS/JS landing page designed for free hosting on GitHub Pages.

## Files
- `index.html` — page structure/copy
- `styles.css` — responsive design + animations
- `script.js` — scroll reveals, progress bar and prototype form behaviour

## Preview locally
Open `index.html` in a browser. For the most reliable preview, run a tiny local server:
`python -m http.server 8000`
then visit `http://localhost:8000`.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload these three site files to the repository root.
3. In GitHub: Settings → Pages.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public Pages address.
7. A custom domain can be added later under the same Pages settings.

## Important
The contact form is intentionally a visual prototype. It does not transmit or store submitted information yet.
